# yt-dlp Studio URL リスト例
# このファイルにダウンロードしたい動画や音声のURLを1行に1つずつ記述してください。
# コメント行は無視されます。

# YouTubeの動画URL
https://www.youtube.com/watch?v=dQw4w9WgXcQ
https://www.youtube.com/watch?v=some_other_video

# YouTubeのプレイリストURL
https://www.youtube.com/playlist?list=PLsome_playlist_id

# SpotifyのトラックURL (yt-dlpが対応している場合)
https://open.spotify.com/track/some_track_id

# SpotifyのアルバムURL (yt-dlpが対応している場合)
https://open.spotify.com/album/some_album_id

# その他の対応サイトのURL
https://vimeo.com/some_video_id
